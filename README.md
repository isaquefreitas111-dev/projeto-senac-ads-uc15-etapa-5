Sistema de Cinema

Projeto desenvolvido para o Projeto Integrador (PI), com o objetivo de criar um sistema desktop para gerenciamento de informações de um cinema.

Sobre o projeto

O sistema foi desenvolvido utilizando Java e MySQL. A proposta é permitir o cadastro e gerenciamento de filmes e suas informações, facilitando a organização dos dados do cinema.

Tecnologias utilizadas
Java
MySQL
NetBeans
JDBC
GitHub
Funcionalidades

O sistema possui funcionalidades para:

Cadastrar filmes;
Consultar filmes cadastrados;
Alterar informações dos filmes;
Excluir filmes;
Registrar análises dos filmes;
Armazenar os dados no banco de dados MySQL.
Estrutura do projeto

O projeto foi organizado utilizando classes Java para representar as principais informações do sistema, além da conexão com o banco de dados MySQL.

Principais classes
Filme – responsável pelas informações dos filmes.
Analise – responsável pelas análises e notas dos filmes.
Cadastro – responsável pelo cadastro e gerenciamento das informações.
Banco de dados

O banco de dados utilizado no projeto é o MySQL.

As informações dos filmes e análises são armazenadas no banco para que possam ser consultadas e alteradas pelo sistema.

Objetivo

O objetivo do projeto é aplicar na prática os conhecimentos aprendidos durante o curso, utilizando programação Java, banco de dados MySQL e desenvolvimento de sistemas desktop.
